# rails-yelp-mvp

An unfinished Ruby on Rails starter for a Yelp-style restaurant review exercise. It contains only the app generated by `rails new`.

## Context

This is the start of the "Rails Yelp MVP" exercise from the Le Wagon web development bootcamp, which I took in 2020. The only code commit is `rails new` (July 2020). The later commits are a GitHub `SECURITY.md` template (November 2020) and a Dependabot bump of Puma (October 2021).

## What is in the repo

- A default Rails 6.0 skeleton: no models, controllers, views, migrations or routes beyond what the generator creates.
- `config/routes.rb` and `db/seeds.rb` are still the generator's empty files.
- The restaurant and review features the exercise asks for were never committed here.

## Stack

- Ruby 2.6.6, Rails 6.0
- SQLite (`sqlite3` gem), Puma
- Webpacker 4, Turbolinks, Sass

## Running it

Running it locally needs Ruby 2.6.6, Bundler, Node and Yarn:

```bash
bundle install
yarn install
rails db:create
rails server
```

This only shows the default Rails welcome page.

## Status

Archived learning project, not maintained. The Ruby and Rails versions it uses are end-of-life.
